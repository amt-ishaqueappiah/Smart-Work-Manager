## what: Generate a pull request description based on the changes made in the code. Use when you create a pr or when user asks to summarize changes.

## when: When a user creates a pull request or requests a summary of changes made in the code.

## why: To provide a clear and concise summary of the changes made in the code, making it easier for reviewers to understand the purpose and impact of the pull request.

## testing: To test this skill, you can create a pull request with a set of changes and then ask the skill to generate a description for that pull request. You can also provide a summary of changes made in the code and ask the skill to generate a pull request description based on that summary.

## Changes: The skill will analyze the changes made in the code and generate a pull request description that summarizes those changes. The description will include information about the purpose of the changes, any new features or bug fixes, and any relevant context or background information. The skill will also provide suggestions for improving the clarity and conciseness of the description.
